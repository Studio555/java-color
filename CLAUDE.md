# java-color

Fork of `EsotericSoftware/color`, packaged as a Java library for Gradle releases.

- Read `README.md` for upstream provenance.
- Library sources live in `src/`.
- `build.gradle` defines Java compatibility, JUnit tests, versioning, and Maven publication.
- Use the checked-in Gradle wrapper and consult `gradle.properties` and `settings.gradle` for build configuration.
